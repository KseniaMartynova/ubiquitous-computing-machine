2. Четыре операции

В эксперименте сравниваются четыре операции над квадратными матрицами размера n * n:
- Cholesky — обращение симметричной положительно определённой (SPD) матрицы через разложение Холецкого. В C++-реализациях: dpotrf + dpotri. В NumPy: cho_factor + cho_solve(эквивалент dpotrf + dpotrs, 7n³/3 операций вместо n³).
- LU — обращение через LU-разложение: dgetrf + dgetri во всех трёх реализациях.
- Multiplication — умножение двух независимых SPD-матриц: dgemm (C++) или np.matmul (NumPy).
- SVD — обращение через сингулярное разложение: dgesdd + dgemm для сборки обратной. Для SPD-матрицы псевдообратная совпадает с обычной обратной.

5. Режимы потоков

Исследуются два режима:
- default — библиотеки сами выбирают число потоков. Обычно это число логических CPU (16), но не гарантируется: в пилоте MKL выбрал 8, OpenBLAS — 16. Конкретное число фиксируется в поле thread_pools каждой строки CSV.
- single — принудительно однопоточно OMP_NUM_THREADS=1, MKL_NUM_THREADS=1, OPENBLAS_NUM_THREADS=1. Все пулы в thread_pools оканчиваются на :1.
